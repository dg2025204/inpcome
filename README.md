# 🔥 가스 감지 LED 경보기

라즈베리파이 피코(Pico), 가스 센서(MQ2), LED 막대(10칸짜리)를 이용해서
공기 중 가스 농도를 눈으로 볼 수 있게 만든 장치입니다.

평소에는 초록색에서 빨간색으로 서서히 채워지는 막대로 공기 상태를 보여주고,
위험한 수준이 되면 전체가 빨갛게 깜빡이고, 진짜 심각한 수준이 되면
"펑!" 터지는 듯한 연출이 나오면서 경고합니다.

## 무엇을 준비해야 하나요

| 부품 | 개수 |
|------|------|
| 라즈베리파이 피코 | 1개 |
| MQ2 가스 센서 | 1개 |
| LED 막대 (10칸, WS2812 종류) | 1개 |
| 연결용 점퍼선 | 여러 개 |

## 어떻게 연결하나요

| 피코 핀 | 연결할 곳 |
|---------|-----------|
| A0 (GP26) | 가스 센서의 AOUT |
| 3V3 | 가스 센서의 VCC |
| GND | 가스 센서의 GND |
| D16 (GP16) | LED 막대의 DIN |
| 3V3 (또는 5V) | LED 막대의 VCC |
| GND | LED 막대의 GND (센서 GND와 같이 연결) |

> LED가 많거나 아주 밝게 쓰고 싶으면 3.3V로는 전기가 모자랄 수 있어요.
> 이 프로젝트는 밝기를 낮게(15%) 맞춰서 3.3V로도 잘 동작하게 해놨어요.
> 나중에 밝기를 더 올리고 싶다면 5V 쪽으로 연결을 바꾸는 게 좋아요.

## 어떤 프로그램으로 돌리나요

- 피코에는 **마이크로파이썬**이라는 프로그램(펌웨어)을 먼저 설치해야 해요.
- 코드를 넣고 실행할 때는 **Thonny**라는 프로그램을 사용했어요.

## 이 장치는 이렇게 동작해요

가스 센서가 읽은 숫자가 얼마나 큰지에 따라 3단계로 반응이 달라져요.

| 센서 값 | 상태 | LED가 하는 행동 |
|---------|------|------------------|
| 1000 미만 | 안전 | LED 전부 꺼짐 |
| 1000 ~ 3000 | 주의 | 초록 → 빨강으로 조금씩 채워짐 |
| 3000 ~ 4000 | 위험 | LED 전체가 빨간색으로 켜지고 서서히 깜빡임 |
| 4000 이상 | 심각 | **폭발 연출** 재생 (하얀 번쩍임 → 불꽃 튀는 효과 → 빨간 점멸) |

이 숫자들(1000, 3000, 4000)은 코드 위쪽에서 직접 바꿀 수 있어요. 센서마다
평소 값이 다르기 때문에, 자기 센서로 직접 측정해보고 상황에 맞게 조정하는 게
좋아요.

## 센서 값은 왜 직접 확인해봐야 하나요

같은 종류의 가스 센서라도 하나하나 살짝씩 값이 다르게 나와요. 그래서
"평소 가만히 뒀을 때 숫자가 얼마나 나오는지", "라이터 가스 같은 걸 가까이
댔을 때 숫자가 얼마나 올라가는지"를 직접 확인한 다음, 그 기준으로 위의
1000 / 3000 / 4000 같은 숫자를 자기 환경에 맞게 바꿔주는 게 중요해요.

측정만 따로 확인하고 싶을 때 쓰는 간단한 코드도 폴더 안에 넣어뒀어요
(`check_value.py`).

## 켜자마자 왜 5초를 기다리나요

가스 센서는 전원을 켜자마자 정확한 값을 주지 않아요. 안에 있는 히터가
데워지는 시간이 좀 필요해서, 프로그램 시작할 때 잠깐 기다리는 시간을
넣어뒀어요. 정확하게 쓰려면 20초에서 1분 정도 기다리는 게 더 좋아요.

## LED 끄는 법

프로그램이 계속 돌아가고 있는 상태에서는 LED가 계속 반응하기 때문에, 먼저
**Thonny에서 정지 버튼을 눌러서 실행 중인 프로그램을 멈춘 다음** LED를 끄는
코드를 따로 실행해야 꺼져요. 이 파일도 폴더 안에 따로 넣어뒀어요
(`led_off.py`).

## 폴더 안에 들어있는 파일들

| 파일 이름 | 하는 일 |
|-----------|---------|
| `main.py` | 메인 경보 장치 코드 (피코에 이 이름으로 저장하면 전원 켤 때마다 자동으로 실행됨) |
| `led_off.py` | LED를 바로 꺼주는 코드 |
| `check_value.py` | 가스 센서 값만 확인하고 싶을 때 쓰는 코드 |

## 자주 겪을 수 있는 문제

**"machine이라는 게 없다"는 에러가 뜰 때**
이건 일반 컴퓨터의 파이썬으로 실행해서 생기는 문제예요. 피코 전용
마이크로파이썬을 설치하고, Thonny에서 피코를 연결한 상태로 실행해야 해요.

**LED가 계속 안 꺼질 때**
1. 이전에 실행하던 프로그램이 아직 멈추지 않고 계속 돌고 있을 수 있어요.
   Thonny에서 정지 버튼을 눌러 완전히 멈춘 다음 끄는 코드를 실행해보세요.
2. `main.py`라는 이름으로 저장해두면 전원이 켜질 때마다 자동으로 실행돼요.
   끄고 싶으면 파일 이름을 바꾸거나 지우고 다시 전원을 켜보세요.
3. 사용하는 LED 막대가 다른 제품보다 신호를 조금 다르게 받아들이는
   타입이라면, 신호 타이밍 설정값을 제품에 맞게 바꿔줘야 정상적으로
   켜지고 꺼져요.

## 참고할 점

이 장치는 취미나 공부를 목적으로 만든 것이라, 실제 화재나 가스 누출을
막아주는 정식 안전 제품이 아니에요. 진짜 안전이 걱정되는 곳에는 반드시
정식으로 인증된 가스 감지기를 사용해야 해요.
